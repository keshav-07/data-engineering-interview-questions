# Contributing

Thanks for helping improve this list.

- **Found a wrong or outdated answer?** Open an issue with the question link and what is wrong. Answers live on
  [DataDank](https://datadank.com/) and are corrected there.
- **Want a question added?** Open an issue with the question as it was asked in an interview, the company type
  (optional) and the level (Easy, Medium, Hard).
- **Fixing a typo or a broken link in this README?** A pull request is welcome.

Please keep issues focused on Data Engineering interview preparation.
